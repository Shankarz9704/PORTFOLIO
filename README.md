## ✨ Features & Architecture

- **Responsive UI/UX**: Mobile-first fluid layout built with HTML5, CSS3 (CSS Grid & Flexbox), and JavaScript (ES6+).
- **Dark & Light Theme**: Toggleable theme switcher with persistent local storage.
- **Dynamic Typewriter**: Animated headline cycling developer roles (*Python & Java Full Stack*, *AI Data Analyst*, *Spring Boot & SQL Developer*).
- **Project Showcase Gallery**: Interactive category filtering (*Full Stack*, *Data Analytics*, *Security*, *Web Apps*).
- **Contact Form**: Form validation with interactive feedback toast.
- **Resume Integration**: Complete breakdown of Education (B.Tech CSE 75%), Work Experience (Concentrix, Altruist, Rooman, TaPTaP, ExcelR), and Certifications (IBM, Cisco, Coursera, MongoDB).
